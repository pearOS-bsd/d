# d — the daemons of pearOS

All the services that run in the background (and the scripts that start them together) in one place; the pearOS build (wsbsd/iso/build.sh) takes them from here.

| folder | what | built with |
|---|---|---|
| `darwin/` | Mach-O daemons for darwinator (they run unmodified Mac programs): `launchd` (Mach bootstrap, services by name), `notifyd`, `wsbridge` (the Mac client library <-> WindowServer), `lsd-stub`/`xpc-stub`, `lsd-objc` (LaunchServices of our own), `svc-stub`, `carender-stub` (CARenderServer), `wm-stub` (WindowManager), `tccd` (TCC: com.apple.tccd.system and com.apple.tccd, wire compatible with the Mac's, see darwin/tccd/README.md), `opendirectoryd` (the libinfo and membership pipes: getpwuid & co and mbr_* from /etc/passwd and /etc/group, darwin/opendirectoryd/README.md), `distnoted` (distributed notifications, @Uv3 per user and @1v3/@0v3 for the system, darwin/distnoted/README.md), `cfprefsd` (the preferences server: com.apple.cfprefsd.agent per user and com.apple.cfprefsd.daemon for the system, wire compatible with the Mac's, darwin/cfprefsd/README.md), `windowmanager` (com.apple.windowmanager.external, the Dock's NSXPC peer of WindowManager.app) and `wallpaperagent` (com.apple.wallpaper, the desktop picture as a CoreAnimation context), the other services the Dock looks up at start (research/docs/DOCK-SERVICES-2.md): `usernoted` (com.apple.usernoted.dock, the badges), `appleeventsd` (com.apple.coreservices.appleevents, the Apple Event check-in), `analyticsd` (com.apple.analyticsd), `filecoordinationd` (com.apple.ProgressReporting, the NSProgress registry), `csnameddatad` (com.apple.carboncore.csnameddata), `dmd` (com.apple.dmd.policy, Screen Time), `useractivityd` (com.apple.coreservices.lsbestappsuggestionmanager.xpc, Handoff) and `uninstalld` (com.apple.uninstall.service), Objective-C or C without an SDK on `darwin/common/` | `sh darwin/build.sh` (llvm21 + ld64.lld; lsd-objc and wm-stub on a Mac). windowmanager and wallpaperagent install as `/usr/libexec/pearos/WindowManager` and `/usr/libexec/pearos/WallpaperAgent` (binaries `out/<dir>/out/<Name>`); the others as `/usr/libexec/pearos/<dir>` |
| `bsd/` | FreeBSD/GNUstep daemons: `launchd` (+ launch agents of the desktop), `usernoted` (+ `wsnotify`), `airportd`, `xpcservices/` (Open and Save Panel Service) | `WSBSD=.. COMPAT=.. sh bsd/build.sh OUT` |
| `session/` | the scripts that bring the daemons up together (stack-dock*.sh, pearos-desktop.sh, pearos-killall.sh): they expect the binaries under `/root/dnew/<name>/` (sync `darwin/` there) | on the VM, as root, after `kldload darwinator.ko` |

Related repositories: `pearOS-bsd/darwinator` (the kernel module), `pearOS-bsd/misc` (wsbsd: the window server WindowServer, the AppKit "open", the desktop programs; its `sdk/` is used by `bsd/`).
History: the sources were moved from `darwinator` (launchd, notifyd, wsbridge, lsd-stub, lsd-objc, svc-stub, carender-stub, hid-stub, wm-stub, tools/stack-*.sh, tools/pearos-*.sh) and from `misc/wsbsd` (launchd, usernoted, airportd, appkit/xpcservices, sdk/build-{usernoted,airportd}.sh); their older history stays in those repositories.
(hid-stub moved to the IOKit repository; dock-prefs and dock-on-wsd.sh are in session/)
